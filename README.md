# پنل مدیریت — اپ ادمین

فایل‌های این پوشه (`index.html`, `style.css`, `app.js`) کل برنامه هستند؛ هیچ مرحله بیلدی لازم ندارند.

## استفاده
1. این فایل‌ها را داخل ریپازیتوری گیت‌هابی که برای اکشن تبدیل به APK استفاده می‌کنید قرار دهید.
2. آیکون و نام نهایی اپلیکیشن را طبق روش خودتان در تنظیمات همان اکشن مشخص کنید (این فایل‌ها فقط محتوای داخل اپ هستند).
3. اکشن را اجرا و APK را نصب کنید.
4. در اولین اجرای اپ، «کد اتصال سیستم» را که از صفحهٔ داشبورد یا تنظیمات پنل وب (`panel/`) روی هاست گرفته‌اید وارد کنید.
5. با کد پرسنلی و کد ملی حساب مدیر وارد شوید.

اگر لازم شد سرور را عوض کنید یا کد اتصال جدیدی بسازید، از دکمهٔ «تغییر سرور متصل» در صفحه ورود استفاده کنید.
